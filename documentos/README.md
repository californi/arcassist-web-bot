# Knowledge-base documents

The local prototype was tested with four software architecture PDFs:

- Perry and Wolf, "Foundations for the Study of Software Architecture" (1992).
- Garlan and Shaw, "An Introduction to Software Architecture" (1994).
- Kruchten, "Architectural Blueprints: The 4+1 View Model of Software Architecture" (1995).
- Jansen and Bosch, "Software Architecture as a Set of Architectural Design Decisions" (2005).

The PDFs are not redistributed in this replication scaffold because licenses and
redistribution permissions must be checked before a public GitHub release.

To reproduce the original setup, place locally obtained PDFs in this directory
and restart the application. The FAISS index will be rebuilt when `rag/index.faiss`
and `rag/docs.npy` are absent.
