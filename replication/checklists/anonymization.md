# Anonymization checklist

- [ ] Remove `.env`, API keys, tokens, credentials, and local logs.
- [ ] Remove Git history before creating an anonymous review artifact.
- [ ] Remove local absolute paths and personal account identifiers.
- [ ] Check screenshots for browser profile, e-mail, or institution leakage.
- [ ] Publish only redistributable documents.
- [ ] Replace private repository or Drive links with an anonymous artifact link.
- [ ] Ensure the paper PDF uses the `anonymous` class option.
